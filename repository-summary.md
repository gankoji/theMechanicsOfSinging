# The Mechanics of Singing - Repository Summary

## Repository Overview
"The Mechanics of Singing" is a comprehensive educational resource hub for vocalists, specifically developed for the Northwest Sound Chorus. This repository combines theoretical knowledge with practical applications, focusing on barbershop harmony and vocal technique.

## Repository Structure

### 1. Main Hub (index.html)
- **Purpose**: Central navigation portal for all educational resources
- **Target Audience**: Northwest Sound Chorus members and vocal enthusiasts
- **Key Features**:
  - Four main educational modules with detailed descriptions
  - Modern, responsive web design using Tailwind CSS
  - Clear navigation pathways to specialized content
  - Information about the Northwest Sound Chorus

### 2. Learning the Instrument (learning-the-instrument/)
- **Focus**: Vocal anatomy and technique fundamentals
- **Framework**: APROAR(TE) methodology
  - **A**udiation: Mental pitch preparation and visualization
  - **P**osture: Physical alignment for optimal singing
  - **R**espiration: Breath control and support
  - **O**nset: Sound initiation techniques
  - **A**rticulators: Speech mechanism control
  - **R**esonance: Sound production and modification
  - **T**echnique: Overall vocal coordination
  - **E**xercises: Practical application drills

- **Interactive Features**:
  - Clickable vocal anatomy diagram with detailed explanations
  - Tabbed navigation for different technique modules
  - Step-by-step exercises for each concept
  - Visual and textual learning aids

### 3. Thematic Elements of Music (thematic-elements/)
- **Focus**: Musical interpretation and expression
- **Core Concept**: Four pillars of musical expression
  - **Melody**: Linear succession of musical tones
  - **Lyric**: Text and storytelling elements
  - **Harmony**: Chordal structures and progressions
  - **Rhythm**: Temporal patterns and groove

- **Educational Materials**:
  - Comprehensive presentation (HTML) with examples and exercises
  - Workshop outline for 60-minute rehearsal sessions
  - Prosody analysis framework for lyric interpretation
  - Vocal "paint palette" techniques for expressive singing
  - Real-world examples from quartets and soloists

- **Key Documents**:
  - "But How Should I Sing It?" - Core presentation on expressive singing
  - Thematic elements outline for structured learning
  - Org-mode notes for advanced analysis
  - Presentation slides with embedded multimedia

### 4. Mechanics of Music (mechanics-of-music/)
- **Focus**: Technical music theory and practical applications
- **Topics Covered**:
  - Rhythm fundamentals and subdivision techniques
  - Tuning concepts (Just Intonation vs. 12-TET)
  - Tonal center awareness and ear training
  - Interval relationships and harmonic structure

- **Practical Exercises**:
  - Metronome training for rhythmic precision
  - Call-and-response marching patterns
  - Rhythmic city names for subdivision practice
  - Pitch matching and fine-tuning drills
  - Myth-busting section on common tuning misconceptions

### 5. Barbershop Analyzer (barbershop-analyzer/)
- **Technology Stack**: React + TypeScript + Vite
- **Purpose**: Specialized tool for barbershop harmony analysis
- **Features**:
  - Harmony analysis tools
  - Barbershop-specific technique assessment
  - Interactive learning components
  - Modern UI with Tailwind CSS and Radix UI components
